# Security policy

## Supported versions

Only the latest minor release of each project gets security fixes (before 1.0.0, the latest
0.x release).

## Reporting a vulnerability

Please do not open a public issue. Use **Report a vulnerability** in the repository's
**Security** tab (`https://github.com/luminare-dev/<repository>/security/advisories/new`). If that
is not possible, email <security@luminare.tech> with the repository name in the subject.

Include the version or commit, what the problem is, and steps to reproduce. Redact real secrets
and personal data.

I aim to reply within 14 days (best effort), fix the issue, and publish an advisory with the
release, crediting you unless you prefer otherwise. There is no bug bounty.

Out of scope: bugs in third-party software a project only installs or monitors (report them
upstream), and scanner output without a demonstrated impact.
