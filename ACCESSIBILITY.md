# Accessibility

The projects here should work with screen readers, keyboard-only use, zoom and high-contrast
settings: real headings in the docs, alt text for images, no information carried by colour alone,
and examples as copyable text. This is best effort, not a formal conformance claim.

If something gets in your way, open a bug report in the affected repository (or a
[discussion](https://github.com/orgs/luminare-dev/discussions) if unsure) and describe what you
tried and the assistive technology you use. If GitHub itself is the barrier, write to
<oss@luminare.tech>.
