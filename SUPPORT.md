# Getting help

This applies to every repository in [luminare-dev](https://github.com/luminare-dev) that does not
have its own `SUPPORT.md`.

## Public channels only

Help happens **in public**, so that the next person with the same question finds the answer:

| You want to… | Go to |
|---|---|
| ask a question, discuss an idea or show what you built | [Discussions](https://github.com/orgs/luminare-dev/discussions) |
| report a bug that you can reproduce | the repository's **Issues** tab, form "Bug report" |
| propose a feature | the repository's **Issues** tab, form "Feature request" |
| report a security problem | **never in public**: follow [SECURITY.md](https://github.com/luminare-dev/.github/blob/main/SECURITY.md) |
| report a Code of Conduct problem | conduct@luminare.tech |

Answers are **best effort**. The maintainers aim for a first reply within 7 days, but there is no
guaranteed response time.

## What is not provided

- **No private support.** Questions sent by direct message, chat or email are answered with a
  pointer to Discussions or Issues.
- **No installs, configuration or fixes on anyone's server, network or account.** Nobody will log
  in to your systems, and you should never share credentials with anyone who offers to.
- **No support for modified versions** or forks, unless the problem also happens with the
  unmodified project.

## Before you ask

1. Read the repository's `README.md` and its `docs/` folder, especially the troubleshooting page
   if there is one.
2. Search the open and closed issues and the discussions.
3. Check that you use the latest release.
4. Collect the versions you use (project, operating system, and the tools named in the README) and
   the exact error message.
5. **Remove all secrets, tokens, licence keys, IP addresses, hostnames and player or user data**
   from anything you paste.

## General contact

For things that are not support requests, such as questions about licensing or a project in
general, write to oss@luminare.tech.
