# Getting help

Help happens in public and is best effort:

- Questions and ideas: [Discussions](https://github.com/orgs/luminare-dev/discussions)
- Bugs and feature requests: the repository's **Issues** tab
- Security problems: never in public, see [SECURITY.md](https://github.com/luminare-dev/.github/blob/main/SECURITY.md)
- Code of Conduct problems: <conduct@luminare.tech>

Before asking, check the README and `docs/`, search existing issues, try the latest release, and
include versions and the exact error. Remove secrets, IP addresses, hostnames and user data from
anything you paste.

There is no private support and no help on anyone's own servers. Other questions:
<oss@luminare.tech>.
